# GenProg: Signal Synthesis via Genetic Programming  
*(Archived Research Code)*

This repository contains archived MATLAB code from early research exploring **genetic-programming–based signal synthesis and matching**.  
The methods implemented here were developed as part of a research line that later contributed to a peer-reviewed **IEEE Transactions** publication in healthcare time-series analysis.

This code is shared **for transparency and methodological reference**. It is **not actively maintained** and is **not intended as a production-ready library**.

---

## Context

The original research focused on:

- symbolic and evolutionary representations for signal modeling  
- fitness-based program evolution  
- exploratory synthesis of structured temporal data  

Subsequent work applied related ideas to healthcare time-series data and resulted in a published IEEE Transactions paper.

---

## Status

- Archived research code  
- Shared for reproducibility and reference  
- Not under active development  
- **Limited documentation by design**  
  Documentation is intentionally minimal, as this repository is shared for methodological reference and transparency rather than as a maintained or general-purpose software package.

---

## Requirements

- MATLAB (tested with versions contemporaneous to the original research)  
- No external toolboxes beyond standard MATLAB functionality  

---

## Usage

The code is organized as a collection of MATLAB scripts and functions under `src/`.  
Entry points and data preparation were experiment-specific and are not standardized.

Users interested in reproducing or adapting the approach should treat this repository as a **reference implementation**, not a turnkey pipeline.
